# CubicYardHub — Universal Material & Takeoff Engine

Professional cubic yard, tonnage, retail bag count, and vehicle hauling payload safety takeoff calculator for concrete, gravel, dirt, sand, and landscaping materials.

## Deployment on Vercel

This is a standard React + Vite Single-Page Application (SPA).

1. **Framework Preset**: Vite
2. **Build Command**: `npm run build`
3. **Output Directory**: `dist`
4. **Install Command**: `npm install`

The included `vercel.json` automatically configures these settings for zero-configuration deployments.

## Local Development

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build test
npm run build
```
